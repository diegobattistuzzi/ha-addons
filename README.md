# Add-on di Diego Battistuzzi

Repository di add-on Home Assistant. Per installarlo:

*Impostazioni → Add-on → Add-on Store → ⋮ → Repository* e aggiungi:

```
https://github.com/diegobattistuzzi/ha-addons
```
